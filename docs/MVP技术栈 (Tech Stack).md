### **MVP技术栈 (Tech Stack)**

[前端] <----> [FASTAPI数据管道服务] <----> [VNPY模拟交易引擎]

#### **技术栈**

- **前端**：
  
  - **KLINECHART**：开源K线图组件，负责渲染模拟交易数据。
  
  - **React / Vue**：框架用于构建前端界面。
  
  - **WebSocket / HTTP API**：用于数据的实时传输。

- **后端**：
  
  - **FASTAPI**：轻量级Web框架，负责处理API请求与WebSocket连接，提供数据服务。
  
  - **Uvicorn**：用于运行FastAPI应用的ASGI服务器。

- **交易引擎**：
  
  - **VNPY**：开源量化交易框架，提供市场数据生成和模拟交易逻辑。

- **数据库**（后期阶段）：
  
  - **SQLite / PostgreSQL**（后期）：数据存储（如交易记录、用户设置等）。

#### **模块化设计**

1. **前端模块**
   
   - K线图模块：使用KLINECHART绘制数据。
   
   - 数据展示模块：负责显示其他交易数据、时间选择、图表切换等。
   
   - 用户交互模块：实现用户数据输入、查询、显示。

2. **后端模块**
   
   - 数据处理模块：通过VNPY处理模拟交易数据。
   
   - 数据传输模块：提供WebSocket或HTTP接口，将数据推送给前端。
   
   - 用户管理模块（后期扩展）：用户认证、权限控制、交易记录管理等。
