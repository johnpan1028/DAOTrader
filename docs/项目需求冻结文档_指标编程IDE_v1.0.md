# 项目需求冻结文档 - 专用指标编程IDE v1.0

## 项目概述

### 项目名称
专用指标编程IDE (Indicator Programming IDE)

### 项目目标
创建一个专用的指标编程集成开发环境，通过简化的DSL语法编写技术指标，编译后生成klinechart能识别的JavaScript指标代码。

### 核心价值
- 降低技术指标开发门槛
- 提供类似TradingView Pine Script或文华麦语言的编程体验
- 自动生成符合klinechart规范的JS指标代码
- 提升指标开发效率和代码质量

## 功能需求

### 1. DSL语言设计

#### 1.1 语法特性
- **声明式语法**：类似Pine Script的简洁表达方式
- **内置函数库**：提供常用技术分析函数（ma, ema, rsi, macd等）
- **数据访问**：简化的K线数据访问方式（close, open, high, low, volume）
- **参数定义**：支持用户可配置参数（长度、颜色、样式等）
- **输出定义**：支持主图和副图指标输出

#### 1.2 语法示例
```
// 移动平均线指标
indicator("Custom MA", "CMA", overlay=true)
length = input(20, "Length")
color_ma = input(#2196F3, "MA Color")

ma_value = sma(close, length)
plot(ma_value, "MA", color_ma)
```

#### 1.3 支持的指标类型
- 主图指标（overlay=true）
- 副图指标（overlay=false）
- 多线指标输出
- 柱状图指标
- 填充区域指标

### 2. IDE编辑器功能

#### 2.1 代码编辑
- **语法高亮**：DSL语法着色显示
- **智能提示**：函数名、参数自动补全
- **错误检查**：实时语法错误提示
- **代码格式化**：自动代码格式整理

#### 2.2 编译功能
- **实时编译**：代码修改后自动编译
- **错误报告**：详细的编译错误信息
- **预览功能**：编译结果预览

#### 2.3 用户体验
- **代码模板**：常用指标模板库
- **函数文档**：内置函数帮助文档
- **快捷键支持**：常用操作快捷键

### 3. 编译器系统

#### 3.1 编译流程
1. **词法分析**：DSL代码分词
2. **语法分析**：构建抽象语法树(AST)
3. **语义分析**：类型检查和语义验证
4. **代码生成**：生成klinechart兼容的JS代码

#### 3.2 输出格式
生成的JS代码必须符合现有klinechart指标格式：
```javascript
export default {
  name: 'Custom MA',
  shortName: 'CMA',
  precision: 2,
  calcParams: [...],
  plots: [...],
  regeneratePlots: function(params) {...},
  calc: function(dataList, indicator, params) {...}
}
```

### 4. 集成要求

#### 4.1 与现有系统集成
- 兼容现有indicators目录结构
- 支持main和sub指标分类
- 保持与klinechart的完全兼容

#### 4.2 文件管理
- DSL源文件存储（.dsl扩展名）
- 编译后JS文件自动生成
- 版本控制支持

## 用户角色

### 主要用户
- **量化交易开发者**：需要快速开发技术指标
- **技术分析师**：熟悉Pine Script或麦语言
- **初级程序员**：希望简化指标开发流程

### 使用场景
- 快速原型开发技术指标
- 将Pine Script指标移植到klinechart
- 学习和实验技术分析算法
- 批量生成标准化指标代码

## 性能要求

### 编译性能
- 小型指标（<100行）：编译时间<1秒
- 中型指标（100-500行）：编译时间<3秒
- 错误检查：实时响应（<500ms）

### IDE响应性
- 语法高亮：实时更新
- 自动补全：<200ms响应
- 文件加载：<2秒

## 兼容性要求

### 浏览器支持
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

### 系统要求
- 基于Web技术，跨平台支持
- 内存占用：<200MB
- 磁盘空间：<50MB

## 验收标准

### 功能验收
1. 能够编写简单的移动平均线指标
2. 编译生成的JS代码能在klinechart中正常运行
3. IDE提供基本的语法高亮和错误提示
4. 支持至少10个常用技术分析函数

### 质量验收
1. 编译错误率<5%（对于语法正确的DSL代码）
2. IDE响应时间符合性能要求
3. 生成的JS代码通过ESLint检查
4. 用户界面友好，学习成本低
