## 核心技术栈

### 1. 数据获取层

#### AKShare
- **版本**: 1.12.x+
- **用途**: 金融数据获取主要接口
- **优势**: 
  - 免费开源，数据覆盖全面
  - 支持股票、期货、指数等多品种
  - API接口简单易用
  - 社区活跃，更新及时
- **安装**: `pip install akshare`
- **主要接口**:
  ```python
  import akshare as ak
  # 股票日线数据
  ak.stock_zh_a_hist(symbol="000001", period="daily")
  # 指数数据
  ak.stock_zh_index_daily(symbol="sh000001")
  # 期货数据
  ak.futures_main_sina(symbol="CU0")
  ```

#### 备用数据源
- **Tushare**: 备用数据源，需要积分
- **Yahoo Finance**: 国际市场数据补充
- **本地CSV**: 离线数据导入支持

### 2. 量化引擎层

#### VNPY框架
- **版本**: 3.9.x+
- **用途**: 量化交易和回测引擎
- **核心组件**:
  - `vnpy.trader`: 核心交易框架
  - `vnpy.app.cta_strategy`: CTA策略引擎
  - `vnpy.app.cta_backtester`: 回测引擎
  - `vnpy.database`: 数据库管理
- **安装**: `pip install vnpy[cta]`
- **关键类**:
  ```python
  from vnpy.trader.object import BarData, TickData
  from vnpy.trader.database import get_database
  from vnpy.app.cta_backtester import BacktesterEngine
  from vnpy.app.cta_strategy import CtaTemplate
  ```

#### 技术指标库
- **TA-Lib**: 经典技术分析指标
- **Pandas-TA**: Python原生技术指标
- **自定义指标**: 基于VNPY框架扩展

### 3. 后端服务层

#### FastAPI
- **版本**: 0.104.x+
- **用途**: RESTful API和WebSocket服务
- **特性**:
  - 高性能异步框架
  - 自动API文档生成
  - 类型提示支持
  - WebSocket实时通信
- **核心依赖**:
  ```python
  fastapi==0.104.1
  uvicorn[standard]==0.24.0
  websockets==12.0
  pydantic==2.5.0
  ```

#### Python运行环境
- **版本**: Python 3.13+
- **虚拟环境**: venv或conda
- **包管理**: pip + requirements.txt

### 5. 数据存储层

#### 数据库选择

**开发环境 - SQLite**
- **版本**: 3.40+
- **优势**: 零配置，轻量级，适合开发测试
- **存储位置**: `./data/vnpy_data.db`
- **配置**:
  ```python
  DATABASE = {
      "driver": "sqlite",
      "database": "vnpy_data.db"
  }
  ```

**生产环境 - MySQL**
- **版本**: 8.0+
- **优势**: 高性能，支持并发，适合生产环境
- **配置**:
  ```python
  DATABASE = {
      "driver": "mysql",
      "host": "localhost",
      "port": 3306,
      "database": "vnpy_data",
      "user": "vnpy",
      "password": "password"
  }
  ```

#### 数据表结构
```sql

    created_at DATETIME

```

本地开发机
├── Python 3.13 + venv
├── Node.js 18+ + npm
├── SQLite数据库

### 生产环境
```
Linux服务器 (Ubuntu 22.04+)
├── Docker容器化部署
├── Nginx反向代理
├── MySQL数据库
├── Redis缓存 (可选)
└── 监控告警系统
```

### Docker配置
```dockerfile
# 后端Dockerfile
FROM python:3.13-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
EXPOSE 8000
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]

# 前端Dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json .
RUN npm install
COPY . .
RUN npm run build
EXPOSE 3000
CMD ["npm", "run", "preview"]
```

## 技术选型理由

### 为什么选择AKShare
1. **免费开源**: 无需付费，降低成本
2. **数据全面**: 覆盖股票、期货、指数等
3. **更新及时**: 社区活跃，数据及时更新
4. **接口简单**: API设计简洁，易于集成

### 为什么选择VNPY
1. **专业性**: 专为量化交易设计
2. **完整性**: 包含完整的回测和交易框架
3. **扩展性**: 支持自定义策略和指标
4. **社区支持**: 国内量化社区广泛使用

### 为什么选择FastAPI
1. **高性能**: 基于Starlette和Pydantic，性能优异
2. **现代化**: 支持异步、类型提示等现代特性
3. **文档自动生成**: 自动生成API文档
4. **WebSocket支持**: 原生支持实时通信

### 为什么选择Vue.js 3
1. **响应式**: 优秀的响应式数据绑定
2. **组件化**: 组件化开发，代码复用性高
3. **TypeScript支持**: 完善的TypeScript集成
4. **生态丰富**: 丰富的第三方组件库
