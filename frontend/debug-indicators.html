DAOTrader 指标板调试工具

测试步骤

  1. 打开主应用: http://localhost:5173/
  2. 点击顶部工具栏的"指标"按钮
  3. 在弹窗中勾选/取消勾选指标
  4. 观察浏览器控制台的调试信息
  5. 检查K线图是否相应变化

预期的控制台输出

当勾选MA指标时，应该看到： Indicators props changed: {ma: true, vol: true, macd: false} ensureIndicator called: MA, enabled: true Creating indicator: MA MA indicator created on main pane 当取消勾选VOL指标时，应该看到： Indicators props changed: {ma: true, vol: false, macd: false} ensureIndicator called: VOL, enabled: false Removing indicator: VOL 当勾选MACD指标时，应该看到： Indicators props changed: {ma: true, vol: true, macd: true} ensureIndicator called: MACD, enabled: true Creating indicator: MACD MACD indicator created on sub pane

常见问题诊断

  • 如果没有看到"Indicators props changed"日志：说明App.vue中的indicatorState没有正确传递给KLineChart组件
  • 如果看到props changed但没有ensureIndicator调用：说明watch监听器有问题
  • 如果ensureIndicator被调用但指标没有显示：说明KLineCharts库的API调用有问题
  • 如果指标重复创建：说明ensureIndicator中的移除逻辑有问题
